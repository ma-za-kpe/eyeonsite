Data marked VERIFIED refers to specific verifiable events or published statistics from named sources. Data marked PROJECTED uses stated methodology from reputable institutions. Data marked ESTIMATED is directionally correct but the exact figure may vary by source/year.

## Glossary

### Platform Terms

| Term | Definition |
|------|-----------|
| **Task** | A discrete verification job posted by a client with location, instructions, checklist, deadline, and budget |
| **Evidence Package** | The structured deliverable: GPS-stamped photos, video, checklist responses, inspector notes |
| **Inspector** | A verified local agent who completes tasks on the EyeOnSite platform |
| **Client** | A diaspora individual or enterprise that posts tasks and pays for verification |
| **Escrow** | Funds held by the platform between client payment and inspector payout, released upon evidence acceptance |
| **Trust Score** | Composite reliability rating for inspectors (0.0–1.0) |
| **Vertical Template** | Pre-configured task structure for a specific use case |
| **Project** | Container for multiple related tasks (e.g., monthly checks on one building) |
| **Evidence Quality Score** | AI-computed score (0.0–1.0) measuring photo clarity, completeness, GPS accuracy, checklist depth |
| **Fraud Signals** | Automated indicators of evidence manipulation (GPS spoofing, photo reuse, impossible travel) |

| **Compose for Web** | Kotlin/JS-based web UI framework from JetBrains; compiles Kotlin to JavaScript |
